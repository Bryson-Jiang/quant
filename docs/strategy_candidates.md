### 机制与计算顺序

在信号日t，对每只参与比较的ETF，用过去120个交易日日收益拟合：

`r_i,d = alpha_i,t + beta_i,t * r_510300,d + epsilon_i,d`

`IVOL_i,t = std(epsilon_i, 过去120日, ddof=1) * sqrt(252)`

因此它衡量相对于沪深300单因子模型解释不掉的波动。高beta、跟随大盘上涨或下跌本身不必然产生高IVOL；某行业独立于沪深300的持续波动也会进入残差，不能把残差全部认定为噪声或必然亏损。窗口和回归只使用信号日及以前数据。

比较名单冻结为：510300沪深300、159915创业板、159995芯片、159875新能源、159928消费、512660军工、515070人工智能、512880证券、512800银行、561360石油产业。510300不回归自身，其IVOL设为缺失、保持原资格，避免因自回归产生零残差优势；所以最多9只实际参与排名。

排名使用这份名单内当日所有具有有效IVOL的ETF，而非仅用已通过动量和均线筛选的ETF。记有效数量为m、IVOL从小到大的平均并列排名为k：

`u = 1 - 2 * (k - 1) / (m - 1)`

有效数量至少3只时，`u < -0.5`的ETF失去本次核心选仓资格，其余保留原资格；等价于排除归一化排名大于75%的尾部。小样本不能机械理解为精确删除25%：9只有效、无并列时排除第8、9名，共2只；并列使用平均排名，实际数量可能不同。

缺少完整历史、报价或有效回归，或同类不足3只时，新增过滤保持中性，仍须满足原有趋势、动量和有效报价要求。未评分不表示无风险，也不会自动获得加分。

完整选仓顺序为：

1. 计算原20/40日动量、20日均线反转评分及原40日趋势资格，同时形成上述IVOL过滤结果。
2. 对同时通过原资格和IVOL过滤的ETF，继续按原评分排序；新增机制不改变评分公式。
3. 在过滤后的合格排名中执行必选第1名、前4名旧仓缓冲及最多3只核心风险ETF。已持有ETF若未通过IVOL过滤，也不能借缓冲保留。
4. 沿用原逆波动权重、8%核心波动预算、70%核心风险上限、30%单只上限和弱市减仓；余款按原国债/现金规则处理。
5. 独立计算512890红利低波卫星，仍是MA200入0%、出+4%、先现金再国债、账户上限30%。

黄金、纳指、日经、恒生科技、豆粕、有色期货、国债和独立红利卫星不参加这项A股IVOL排名。过滤改变核心入选者后，这些核心资产的实际权重仍可能间接变化。卫星叠加后，全账户仍可能突破核心8%/70%预算；本候选没有新增全账户硬风险上限。

这是一项周度选仓过滤，没有新增盘中止损、每日强制卖出或大盘涨跌预测。某持仓周中IVOL升高，仍等周信号及下一交易日执行；候选不能保证及时避开急跌。

### 后续如何判断

登记后保持120日、原比较名单和排名门槛不变，用后续新交易周对照默认，观察净收益、回撤、换手、被过滤持仓及其后续收益，尤其是是否错过行业持续上涨。任何新窗口或门槛另记为新试验，不能回写本候选的参数或把已看过的历史称为样本外。

本轮117项场景的家族平均日收益增益校正p约0.09—0.14，未达到5%显著性；该值不是本候选单独的夏普检验。市场IVOL120低波动效用的5/20日RankIC约0.050/0.047，但扩展时序预测R²仍略为负，不能据此宣称强收益预测能力。当前历史池的后视偏差、此前多轮选择及未来市场变化仍未消除。

IVOL名称取自特质波动研究。[Ang等（2006）](https://doi.org/10.1111/j.1540-6261.2006.00836.x)以Fama–French模型研究股票特质波动；这里是沪深300单因子ETF残差代理，没有复现原文FF3，也不是期权隐含波动率。只比较残差风险的筛选作用，不将原论文结论直接等同于A股ETF盈利保证。
